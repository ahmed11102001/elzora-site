## Integration notes (for the 7.0-7.3 agent)

- Migration is numbered 0020 to avoid the 0002-0009 range. If 7.2 also creates trips / trip_translations /
  redirects, merge the two before applying: the dashboard expects the columns in 0020 (translation status,
  slug_history, jsonb itinerary, unique (locale, slug) where slug <> '').
- Trip ids are text (the seed uses the old slug-like ids, new trips use UUIDs).
- slugTaken() also checks `redirects`, so an old URL is never reused by another trip.
- slug_history -> redirects rows are written on save; the 301 lookup in the public trip page is 7.4D / 7.3.
- Media still points at photo ids from the image pipeline; signed uploads + media_assets are not part of 7.4C.
- Not done here: separate Postgres roles (plan D2); use ADMIN_DATABASE_URL once the roles exist.
