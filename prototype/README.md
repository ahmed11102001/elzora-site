# Journey prototype

`journey-prototype.html` is the standalone HTML prototype of the scroll journey (map intro, five
stations, finale). Open it in a browser. Photos are embedded as base64, so the file is large.

It is the reference for **Phase 4** (port into `src/components/journey`, data-driven, lazy-loaded).
Do not ship it. Some photos still need a license check (see `TASKS.md`, Phase 0).
