## Behaviour

- Publish: only from "review", re-checks every publish blocker on the stored data (slug, SEO, image + alt,
  itinerary, EN/DE day numbers, licences when enforced), stamps publishedAt, audit log, cache refresh.
- Unpublish: back to "draft", publishedAt cleared, slug history kept (old URLs are never reused).
- Editing a published translation stays live; the save re-validates it and refreshes the cache.
- Preview: dashboard signs a link to the public host. /api/preview verifies it, enables Draft Mode and sets an
  httpOnly cookie holding the token. Same 404 for a bad token and a missing secret.

## Integration with 7.0–7.3 (the public side must do these)

1. Tag cached reads with TRIPS_TAG / tripTag(id) / SITEMAP_TAG from src/admin/publishing/tags.ts
   (or move that file to a shared place). Without tags, the refresh has nothing to expire.
2. In the trip page: if the translation is not published, call hasPreviewAccess(tripId, locale); show the
   draft only when true, otherwise 404. Read it in dynamic code, not inside a cached function. Mark preview
   pages noindex and uncached.
3. Replace tripPublicPath() with the shared route-map helper (de uses /de/reisen/<slug>).
4. Serve 301s from the `redirects` table (7.4C) only when the target translation is published.
5. Sitemap: published translations only, tagged SITEMAP_TAG. hreflang: published translations only.
6. Set PREVIEW_SECRET on the dashboard AND the public deployment (same value).
